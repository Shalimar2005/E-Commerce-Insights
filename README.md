## E-Commerce Insights Dashboard
An interactive Power BI dashboard analyzing e-commerce sales, profit, customer segments, product performance, and regional trends.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Excel

## 📈 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Order Value (AOV)
- Profit Margin %

### Business Insights & Recommendations

## 🔍 Key Insights
- Technology is the top-performing category.
- Consumer segment generates the highest sales.
- Sales show consistent growth over time.
- Top products contribute significantly to revenue.

## 💡 Recommendations
- Focus on high-performing products.
- Improve discount strategies.
- Strengthen customer retention.
- Expand in profitable regions.
